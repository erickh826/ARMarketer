# ARMarketer 專案目標與需求定義

## 一、專案背景與痛點
建置公司自有的 Web AR/VR/3D Marketing Platform，取代 Zapworks 訂閱服務。

### 核心痛點
1. **模型壓縮限制：** Zapworks 25MB 單檔限制，逼迫美術交出低品質模型，視覺體驗被打折。
2. **成本結構：** 放寬上限的方案月費過高，不符效益。
3. **流程綁定：** AR 紀念卡 / 印刷品 AR 是年度 10+ 專案的常態，受制於平台功能限制。

## 二、需求定義
### 2.1 核心需求
| 項目 | 內容 |
| :--- | :--- |
| 主要內容類型 | 360° 全景、3D 模型、Image Tracking AR（印刷品掃描） |
| 模型大小策略 | 原檔無硬性上限；自動轉檔後目標 < 10MB |
| AR 觸發方式 | 印刷品圖像辨識（紀念卡、名片、海報、包裝） |
| 主要裝置 | 手機瀏覽器（iOS Safari / Android Chrome） |
| 內容管理 | CMS 支援上傳與管理印刷品圖與 3D 素材 |
| 分享方式 | 公開連結 + QR Code |

### 2.2 非功能性需求
- 首屏 < 5 秒，完整 load < 30 秒。
- 高品質視覺（優於或等同 Zapworks）。
