# 驗收標準與風險

## 九、驗收標準
### AR 驗收 (Phase 1)
- Marketing 可在 CMS 上傳印刷品設計圖，系統自動產生 AR 體驗。
- 手機瀏覽器掃描印刷卡片，3D 內容在 3 秒內顯示。
- 100MB FBX 上傳後轉檔 < 5 分鐘，輸出 < 10MB glb。
- 轉檔後模型視覺品質美術判定「等同或優於 Zapworks」。
- 至少 3 張舊 Zapworks 紀念卡在新平台重現成功。

## 八、風險
- **Zapworks 遷移：** 舊卡片無法直接遷移。應對：開發批次匯入工具或分批重製。
- **MindAR 穩定度：** 若辨識穩定度不足，評估付費 Zappar Universal AR SDK。
