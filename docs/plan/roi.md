# 投資報酬分析 (ROI)

## 現況成本 (Zapworks)
- 每月固定訂閱費 ($X USD/mo)。
- 每次 Campaign 美術需花費 N 小時壓縮模型，品質卻仍受限。
- 客戶投訴「模型糊」，導致反覆修改與負面溝通成本。
- 年度 10+ 專案均受限於模型大小與平台功能。

## 自建後效益
- **美術工時減省：** 美術僅需提供原始高品質檔案，Pipeline 自動完成最佳化。
- **品質提升：** 複雜場景、高品質貼圖不再受 25MB 限制。
- **長期資產：** 完全自有平台、自有流量數據、自由開發 AR 體驗。
- **成本效益：** 月費歸零，轉為維運成本（R2 流量與 VPS）。

| 情境 | 原 FBX | Zapworks 壓縮後 | 自建平台 .glb |
| :--- | :--- | :--- | :--- |
| 中型產品 | 80MB | 22MB (糊) | 6MB (清晰) |
| 複雜場景 | 180MB | 無法上傳 | 12MB |
