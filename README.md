# 3D Model Viewer

This project turns the original proof-of-concept viewer into a Vite + React + TypeScript application.

## Features

- Upload `.obj` and `.fbx` files directly in the browser
- Load a demo OBJ model for quick testing
- Orbit, zoom, and pan around the scene
- Toggle model auto-rotation
- Responsive control panel and viewer layout

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
